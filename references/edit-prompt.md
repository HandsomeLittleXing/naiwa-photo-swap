# 中文编辑提示词模板

只填写本次任务涉及的选项。用户的具体要求始终优先于模板默认值。

```text
图片 1 是风景照片，也是唯一的编辑底图。图片 2 及之后是奶蛙角色参考：[写明每张参考图用于造型、表情或动作]。将[指定人物]替换为奶蛙，保留原位置、视觉尺寸、拍摄角度和画面裁切。

角色造型：参考图中的柔和金黄色梨形身体；可见时保留浅奶油色肚皮；眼睛是间距较宽、微微凸起的薄荷绿圆形眼圈与纯黑瞳孔；嘴型为[用户指定的表情]；四肢短而圆润，表面为带细微质感的哑光材质。不要变成普通青蛙或黄色人脸面具。

动作与人物细节：[沿用底图人物姿态，或采用指定参考动作]；[按要求保留或去除头发、帽子、眼镜、衣服和道具]。其他人、动物、物品、风景及重要的可读细节保持原样。

照片融合：匹配底图的光线、透视、接触阴影、焦点与颗粒。采用克制的 Portra 400 / Pro 400H 风格 35mm 胶片观感：温暖褪色、较低饱和与对比、细腻颗粒、轻微高光晕染和浅景深。漏光与划痕保持很淡。

避免：新增物体或文字、改动风景、拼贴边缘、塑料感、过大的眼睛、不符合要求的夸张笑容，以及参考图的白底或黑色杂块。
```

若只替换面部，要明确限定修改范围，并保留用户指定的头发、眼镜、衣物、身体和姿态。若替换整个人物，可让轮廓变为奶蛙的梨形体态，但脚部仍须自然落在原场景中。
